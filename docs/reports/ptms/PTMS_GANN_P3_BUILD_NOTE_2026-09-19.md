### 3.3 GF-10 notes (derived; no choice)

- **The contrast's A1 zeros use contrast eligibility known only at u.** CE (matched, complete,
  DB-homogeneous) is fixed at the candidate's up-switch close u (v0.8 §4 phase D). The observations are
  built after the pass, so a week before u can carry the candidate's 0 once it is known to be CE. An
  unmatched or censored candidate contributes nothing to the contrast, not even 0s (NC-8, OPEN-J).
- **Every same-type move completed in E had a candidate.** A move is a member of E only if it was
  confirmed at a close where E already held its σ (SC-3, RQ-1). That close forms the candidate, so
  banking at the candidate's end covers the whole ledger. The independent time-leg reference in the
  tests banks moves by the same rule and agrees on every event.
- **P2 price flags** are a recorded fact, not a score (v0.8 §3.9). They enter no statistic and are not
  computed.

## 4. Compute budget (engineering, not a definition)

- G-9a requires every one of the 200 pseudo-real panels to be tested with its own B = 1999
  surrogates. That is about **400,000 panel evaluations**, plus B = 1999 for the real test. One set of
  panels can serve all three constructs.
- Timing: vectorized K3 takes **≈ 0.21 s per 180-stock panel** on one core (synthetic panels,
  2,919 sessions), so **≈ 23 h** for the size check's K3 alone.
- Scoring, outcomes and the GF-10 ledger will add to that. The machine has 4 cores and no numba.
- **Expectation:** a size-check run of days, not hours. This is recorded so that the operator is not
  surprised at run time. It does not change G-9a.
- Both phases checkpoint every unit to `data/ptms/gann_stage1/<digest>_<panel hash>/` (git-ignored).
  Each unit is fixed by its seed, so an interrupted run resumes with identical numbers.
- **Known stop.** If T_c is undefined on some panel (no formation date with ≥ 20 names and a defined
  IC), `rank_p` raises and the run stops. The freeze does not provide for this case, so it goes to the
  operator. The likeliest place is a GF-10 contrast leg on a surrogate or pseudo-real panel: contrast
  weeks are thin (a 90-stock synthetic panel produced none that qualified).
